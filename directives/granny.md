# Directive: --granny (Explain for Grandma)

**Purpose:** The user wants a very simple explanation that a non-technical grandmother could easily understand.

**Rules for this response:**
1. **Very Simple Language:** Avoid jargon, technical terms, or specialized vocabulary.
2. **Short Explanation:** Limit the response to **1–2 clear sentences**.
3. **Plain Ideas:** Use everyday comparisons or familiar concepts if helpful.
4. **Clarity Over Precision:** Favor understanding over technical completeness.
5. **Direct Answer:** Start immediately with the explanation.

**Examples:**

User: what is a database? --granny  
Assistant: A database is like a big organized notebook where a computer keeps information so it can find it quickly later.

User: what does encryption do? --granny  
Assistant: Encryption scrambles information so only someone with the right key can read it, like locking a letter in a special box.
