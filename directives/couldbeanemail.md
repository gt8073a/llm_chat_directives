Directive: --couldbeanemail

Purpose:
Evaluate any proposed meeting to determine whether synchronous time is necessary, who must attend, and whether an asynchronous artifact would be more efficient. Produce a structured, defensible justification that can be dropped directly into a meeting invite.

1. Recommendation Header
Choose one:
• Optimized Sync & Artifact Focus — A live meeting is required, but only for Required attendees. Follow-up documentation is mandatory.
• Document-Driven Review (No Sync) — The objectives can be met asynchronously. Cancel the meeting and distribute the artifact for review.
• Refine Scope & Reschedule — Inputs are incomplete or scope is unclear; refine the artifacts before scheduling.

2. Explain to Grandma
Give one plain-language sentence explaining *why people must gather live*. If Grandma cannot understand the need for a meeting, the Decision Required Live metric should be ★.

3. Metrics (Stars Only)
Rate each metric as ★ (low), ★★ (medium), or ★★★ (high):
• Complexity — Technical or organizational difficulty; number of unknowns.
• Criticality — Urgency and impact of delay.
• Decision Required Live — Whether immediate group consensus or conflict resolution must happen in real time.
• Cross-Team Alignment — Number of teams whose buy-in is mandatory.
• Asynchronous Feasibility — How effectively this goal can be reached by document, email, or comments.

4. Rationale for Each Metric
For each metric above, briefly explain *why* it earned its score, tied directly to the meeting content.

5. Required / Optional / Not Needed
Categorize attendees:
• Required — Must be in the room to provide input or approval.
• Optional — Can join but may rely on notes.
• Not Needed — Can rely entirely on outputs and do not need synchronous time.

6. Document Links
List any PRDs, project plans, GitHub issues, docs, or artifacts used to assess the meeting. Note if critical documentation is missing.

7. Justification Summary (Ready for Invite)
Provide a short paragraph (4–6 sentences) summarizing the metrics, clarifying the necessity of the sync (or lack thereof), and framing the meeting’s purpose in a way suitable for pasting directly into a meeting invitation.

Output Format (always in this order):
Recommendation Header
Explain to Grandma
Metrics Table
Rationale for Each Metric
Required / Optional / Not Needed
Document Links
Justification Summary (Ready for Invite)

END OF DIRECTIVE
